How I work

Good models begin with better questions.

I treat model quality as one part of a larger product system: data quality, evaluation design, failure modes, latency, cost, and user behavior all matter.

01

Frame the decision

Start with the behavior or decision the system should improve—not a model family.

02

Earn complexity

Build a measurable baseline first, then add sophistication where evidence supports it.

03

Evaluate the chain

Test every critical step and the complete user outcome, including known failure modes.

04

Design for trust

Expose sources, uncertainty, freshness, and limitations at the point of use.
